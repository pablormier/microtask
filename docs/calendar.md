# Calendar setup

Microtask can use calendars connected to your agent app when choosing work or
planning the week. Your app supplies access; microtask stores calendar IDs and
interpretation guidance in workspace policy.

Follow the [calendar setup guide](../.agents/skills/microtask/references/calendar.md)
to connect your app, select calendars, edit `mt-policy.local.yaml`, and verify
the result. This guide also ships with installed microtask skills so agents
can help configure calendars from other projects.
